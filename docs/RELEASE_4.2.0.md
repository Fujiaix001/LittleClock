# LittleClock 4.2.0

## 友善設定頁

- 將原本集中在單一長頁面的設定重新分成「相簿與播放、時鐘與版面、天氣、電源與顯示、番茄鐘與鬧鐘、相片效果與維護」六個類別。
- 每個類別可獨立展開或收合，預設只展開常用的相簿與播放設定。
- 設定名稱與目前值改為上下排列，避免小螢幕上的文字與選單互相擠壓。
- 「取消」與「儲存並返回」固定在畫面底部，不必捲回頁首才能完成設定。
- 天氣、夜間模式與鬧鐘的相關選項只在功能啟用時顯示。
- 放大勾選框與操作列的觸控範圍，並補上類別及儲存按鈕的無障礙說明。

## 相容性

- 保留全部既有設定鍵、預設值、情境內容與儲存流程；4.1.1 使用者可直接升級。
- 不新增權限、背景服務、執行期依賴或網路行為。
- 維持 Android 4.2（API 17）到 Android 16（API 36）的支援範圍。
- standard `versionName` 為 `4.2.0`，storopiaTest 為 `4.2.0-test-android4.2-storopia`。
