# LittleClock 4.1.0

## 顯示與播放

- 新增秒數顯示：可關閉、只在充電時顯示，或永遠顯示。
- 秒數使用獨立的每秒文字更新；秒數關閉、夜間暗屏或離開 App 前景時不啟動每秒 ticker。
- 新增播放順序：隨機（每輪不重複）、檔名 A → Z、檔名 Z → A、最新優先、最舊優先。
- 播放排序只使用檔名與檔案／SAF 修改時間，不讀取 EXIF；EXIF 方向修正維持原有用途。
- 保留原本隨機播放、上一張／下一張歷史與收藏／隱藏相片行為。

## 情境模式

- 新增四個可手動切換的情境：預設、桌面、床頭、展示。
- 情境可保存相簿、排序、轉場、字型、時鐘版面、天氣顯示、秒數與電量顯示等設定。
- 收藏、隱藏、鬧鐘、番茄鐘、天氣地點／快取與 SAF 授權不會被情境覆蓋。
- 從 4.0.29 升級時，既有設定會保留在預設情境，其他情境先以相同設定初始化。

## 充電與電量

- 新增保持螢幕模式：永遠保持亮屏、只有充電時、跟隨系統休眠。
- 新增選用的低電量守護：低電量時暫時降低相片效果，極低電量時暫停自動換圖與相片平移；時鐘、鬧鐘與番茄鐘仍正常。
- 新增電量顯示：永遠顯示或只在未充電時顯示；顯示時固定在主畫面右上角。
- 電池監測只在主畫面前景註冊，不新增常駐服務或背景執行緒。
- 無電池電視盒維持供電裝置行為。

## 相容性與網路

- 保留 Android 4.2（API 17）相容性，target SDK 維持 36。
- 不新增 Android 權限、第三方執行期依賴或背景服務。
- Android 4.2～4.4 取得天氣所需的既有 HTTPS → HTTP 降級行為維持不變。
- 從 4.0.29 升級可沿用同一 release 簽章直接覆蓋安裝。
