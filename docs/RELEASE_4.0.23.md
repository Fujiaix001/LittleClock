# LittleClock 4.0.23

## 三段效能模式

- 新增「低耗電」、「標準」與「展演（高耗能）」三段效能模式。
- 舊版 `low_power_mode` 會自動遷移為低耗電或標準，不會改變原本設定。
- 低耗電與標準模式保留 4.0.22 的行為。

## 展演模式

- 照片平移目標由約 15 FPS 提升至約 30 FPS。
- 增加受限制的電影式平移與緩慢縮放。
- 依照片主色顯示低透明度色彩光影，僅在換照片時淡入。
- 照片轉場期間使用暫時硬體圖層，結束後釋放。
- 不新增第三張全尺寸照片 Bitmap，不使用即時模糊或常駐背景服務。

## 安全降級

- 展演模式每 60 秒檢查一次電池溫度。
- 無法讀取電池溫度時，展演模式不會啟用，會回到標準；若已在低耗電降級狀態則維持低耗電。
- 約 40°C 降為標準，約 43°C 降為低耗電；降級只影響當次執行，不改變使用者設定。
- Android 回報記憶體壓力時暫時降低效果，嚴重低記憶體時停止照片平移並釋放柔和背景。
- 溫度降回安全範圍、記憶體壓力解除後，才恢復展演模式。
