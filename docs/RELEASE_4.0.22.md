# LittleClock 4.0.22

## 手動更新手勢

- 在空白背景長按約 0.9 秒後，向下拉動約 72dp，觸發手動更新。
- 手動更新會立即重繪時間、日期、鬧鐘與番茄鐘顯示，並強制取得最新天氣資料。
- 只長按、不下拉時，仍會開啟原本的「相片操作」選單。
- 時鐘區塊拖動、左右滑動換照片與設定按鈕不會觸發更新。
- 手動更新設有 30 秒冷卻時間，避免誤觸造成重複網路請求。
- 更新失敗時保留原有天氣快取，不影響相片播放。

## 資源與相容性

- 沿用既有天氣背景執行緒與 Wi‑Fi 檢查。
- 不重新掃描整個照片資料夾，避免低階裝置因手動更新而增加記憶體與 I/O 負擔。
- 不新增背景服務或第三方手勢元件，維持 Android 4.2 相容性。
