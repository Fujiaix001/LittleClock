# LittleClock 4.0.27

## 畫面與穩定性修正

- 補齊設定頁共用字型缺少的「展、演」字形，避免單獨回退成系統字型。
- 延伸天氣改為依照目前天氣的實際高度向下排列，放大後不再互相重疊。
- 番茄鐘執行期間，時間、日期與天氣暫時使用預設大小固定在右下角。
- 離開番茄鐘後恢復使用者原本儲存的位置、比例與排版，不覆寫設定。
- 修正原始綁定排版離開番茄鐘時，因插入空 ViewGroup 的索引錯誤而閃退。

## 相容性

- 保留 Android 4.2（API 17）相容性。
- 不新增背景服務、執行緒或第三方執行期依賴。
- 沿用 4.0.26 發行金鑰；從 4.0.26 升級可直接覆蓋安裝。
